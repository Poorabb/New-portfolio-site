Aria
Voice Assistant · Agentic AI

Aria — Personal Voice Assistant

A Jarvis-style Windows voice assistant powered by a LangGraph ReAct agent on Gemini 2.0 Flash, orchestrating 15+ tools across OS control, media, and third-party APIs. Runs a fully offline speech pipeline — faster-whisper for STT, pyttsx3 for TTS, custom energy-based VAD and wake-word detection — eliminating per-request API costs. Dynamic app-discovery via Windows Registry and Start Menu scanning, a thread-safe 3-mode operating system (Normal / Mute / DND), and a custom PyQt6 status overlay for real-time agent state.
